# Чеклист доступности компонентов

Живой документ набора, не отчёт одного обхода. По карточке принимается каждый компонент и строится клавиатурный проход. Аудитор сверяет код с этим файлом и уже записанное не повторяет. Как правки попадают в файл — `audit-workflow.mdc`, сверка «Доступность». Данные сняты с кода, не с имён пропов. Если поведение из кода не следует однозначно — это написано прямо.

Охват на 16.08: 38 компонентов набора в `extension-vite-ts-starter` — все папки `src/ui/*` с `index.tsx` (включая сателлиты Table и CalendarPanel) плюс `src/components/profile-menu`. Компоненты `caption-downloader` добавляются по мере портирования набора.

Модуль `src/ui/open-control/` — хром open-контролов, своей карточки нет. `OpenControlChevron` — `Icon` без кнопки внутри триггера Listbox и RangeInput, остановкой Tab не является. `OpenControlClear` — кнопка сброса этих двух компонентов; её имя описано в их карточках.

Закрытая находка из перечня не удаляется: у неё меняется пометка. Иначе следующий обход принесёт её снова как новую.

## Как читать карточку

Шесть пунктов у каждого компонента:

1. Роль корня и откуда она берётся.
2. Источник доступного имени — откуда именно, и что будет, если вызывающий код подпись не передал.
3. Карта клавиш и число остановок Tab у композиции.
4. Фокус при открытии и закрытии, есть ли ловушка Tab.
5. Какие `aria-*` состояния объявляются и на каком узле.
6. Известные исключения и открытые находки.

## Дерево доступности и остановка Tab — это не одно и то же

Узел может быть в дереве доступности и читаться скринридером, но не быть остановкой Tab. И наоборот: остановка Tab без имени — дефект.

- **Нет в дереве доступности:** `aria-hidden`, `display: none` / `hidden`, презентационный узел без имени, декоративный префикс.
- **Есть в дереве, но не остановка Tab:** статический текст, заголовки, подписи полей, `role="status"`. Скринридер читает их в порядке чтения и находит навигацией по заголовкам.
- **Остановка Tab:** нативный фокусируемый контрол или узел с `tabIndex={0}` (не `-1`).

Заголовок и подзаголовок Card табом не достаются — и не должны. Это не дефект. Дефект был бы, если бы `<h2>` не было в дереве или у интерактивного узла не было имени.

## Два способа связать подпись

Это разные модели. В карточках они не смешиваются.

**Обёртка-`label`.** Checkbox, RadioButton, Switch: подпись — `children` внутри `<label>`, нативный клик по тексту переключает контрол. Без `children` обёртки нет (кроме Switch — он всегда в `label`), имя должно прийти через `aria-label` / `aria-labelledby` на сам `input`.

**Отдельная подпись через `FieldLabel`.** Input, SearchField, Button: `FieldLabel` с `htmlFor` на id контрола. Пустой `label` → `FieldLabel` возвращает `null`, связи нет. У нативного поля значение читается вместе с этой связью.

**Подпись как цель `aria-labelledby`.** DateRangeInput, Stepper, SegmentButton: `FieldLabel` несёт `id`, не `htmlFor`. Корень группы или поле ссылается на этот id. Это не `htmlFor`-связь.

**Подпись и значение кнопки-триггера.** Listbox вида `field` и RangeInput: `FieldLabel` несёт и `htmlFor` (клик по подписи), и `id`. Кнопка называет себя через `aria-labelledby` подписи и узла значения. Иначе `<label for>` на `<button>` перебивает видимое значение. Вид Listbox `icon` подпись не рисует: имя — `resolveTriggerAccessibleName` в `aria-label`.

## AnchoredPanel

1. **Роль.** Корня нет: клонирует единственного ребёнка и ставит `popover`. Роль задаёт вызывающий код на панели.
2. **Имя.** Своего имени нет. Имя — у панели вызывающего кода.
3. **Клавиши.** Tab внутри панели закольцован (`useFocus`). Escape, клик снаружи и уход якоря из полной видимости — `useAnchoredDismiss`. Стрелки, Home, End, Enter, Space — не обрабатывает.
4. **Фокус.** При открытии вызывает `onOpenFocus(panel)` на следующем кадре, если колбэк передан; сам фокус не ставит. При закрытии ловушка возвращает фокус на `returnFocusRef` или на элемент, активный до открытия. Ловушка Tab встроена, пропом не выключается.
5. **Состояния.** Не объявляет. `open` только включает хуки и `showPopover`.
6. **Находки.** Без `onOpenFocus` место фокуса при открытии из этого модуля не следует.

## Button

1. **Роль.** Корень — `div` (`StyledButtonRoot`). Кнопка внутри — нативный `<button>` (`StyledButton`).
2. **Имя.** Видимое имя — `children` в `<button>`. Подпись над кнопкой — `FieldLabel htmlFor={buttonId}`; без `label` подпись не рендерится, имя кнопки остаётся содержимым. Пустые `children` тип не допускает.
3. **Клавиши.** Нативные Enter и Space. Одна остановка Tab на `<button>`. Подпись табом не достаётся.
4. **Фокус.** Не открывается и не закрывается. Своего возврата фокуса нет.
5. **Состояния.** Нативные `disabled`, `type` (дефолт `button`). `active` — визуальный проп, в ARIA не выставляется.
6. **Находки.** Нет.

## Card

1. **Роль.** Корень — `StyledCard` (`div` по умолчанию). Проп `as` меняет тег на `article` или `section`. Явного `role` нет: роль даёт тег. Уровень заголовка задаёт `titleLevel` (от `h1` до `h6`, дефолт `h2`), подзаголовок — `<p>` и уровня не получает. Шапка — `<header>`.
2. **Имя.** Card генерирует id заголовка (`useId`) и связывает его с корнем через `aria-labelledby`, когда тег несёт роль и передан заголовок. На корне-`div` не связывает: без роли называть нечего. Явный `aria-labelledby` вызывающего кода побеждает вычисленный. `titleId` — переопределение id заголовка для случая, когда тем же заголовком называют другой узел (индикаторы в гейте и зонде Browser AI).
3. **Клавиши.** Своих нет. Остановки Tab — только `headerActions` (каждая кнопка ряда, если есть `ariaLabel`). Заголовок и подзаголовок **не** остановки Tab и **не должны** ими быть: они есть в дереве доступности и читаются в порядке чтения / навигацией по заголовкам.
4. **Фокус.** Не открывается. Ловушки нет. В разметке ряд действий идёт после шапки и перед телом: скринридер называет карточку раньше кнопки, а первым фокусируемым узлом внутри диалога оказывается действие шапки.
5. **Состояния.** Не объявляет. Действия шапки пробрасывают `aria-expanded` / `aria-controls` на кнопки ряда, если их передал вызывающий код.
6. **Находки.** Открытые №4, №5 и №6 закрыты проходом 17.08. Находка №10 закрыта проходом 19.08.

## Checkbox

1. **Роль.** С `children` корень — `<label>` (`StyledCheckboxRoot`), внутри `<input type="checkbox">`. Без `children` корень — сам `input`.
2. **Имя.** С `children` — текст внутри обёртки-`label` (не `htmlFor`, не `FieldLabel`). Без `children` имени нет, пока вызывающий код не передал `aria-label` / `aria-labelledby` на `input`.
3. **Клавиши.** Нативные Space / Enter браузера. Одна остановка Tab на `input`. Подпись табом не достаётся, клик по ней переключает контрол.
4. **Фокус.** Нет панели.
5. **Состояния.** Нативный `checked` / `disabled`. В Listbox презентационный экземпляр несёт `aria-hidden`, `readOnly`, `tabIndex={-1}`.
6. **Находки.** Публичное имя `Checkbox` в карту не внесено: корень то `label`, то `input`.

## DateRangeInput

1. **Роль.** Корень — `div`; при переданном `label` ещё `role="group"` и `aria-labelledby`. Триггер — два сегмента-кнопки (`SegmentButtonParts`) + опциональный сброс. Панель — `div` с `role="dialog"` и `aria-modal`.
2. **Имя.** Подпись над рядом — `FieldLabel id={labelId}` без `htmlFor`; связь — `aria-labelledby` на группе. Без `label` группы нет, сегменты именуются своим видимым текстом даты или пустым сегментом. `startLabel` / `endLabel` — `title` сегмента и фрагмент `aria-label` сброса, видимым лейблом сегмента не являются. Панель — константа `aria-label` «Date range calendar».
3. **Клавиши.** Сегменты — нативные кнопки (Enter / Space); ArrowDown открывает панель. Escape закрывает без подтверждения (`useAnchoredDismiss`; кнопка Close совпадает по смыслу). Enter в панели подтверждает диапазон, кроме фокуса на Reset (чистит черновик) и Close (закрывает). Стрелки по дням — в CalendarPanel. Остановки Tab закрытого ряда: два сегмента + сброс. В панели — три: навигация месяца, сетка дней, кнопки подвала (roving в каждой).
4. **Фокус.** При открытии — выбранный день, иначе сегодняшний, иначе первый доступный. При закрытии — на ряд-триггер (`returnFocusRef` пишется в `triggerRowRef`). Ловушка Tab есть.
5. **Состояния.** Сегменты: `aria-expanded`, `aria-controls`, `aria-haspopup="dialog"`, `aria-current` при `active`. Панель: `aria-modal`.
6. **Находки.** Открытые №8 и №14 закрыты проходом 19.08.

## CalendarPanel

1. **Роль.** Корень — `div`. Навигация — `<button>`. Сетка — `role="grid"` с именем от заголовка месяца (`aria-labelledby`). Строка — `row`, день недели — `columnheader`, день — `gridcell` + `<button>`. Заголовок месяца — `<p>`.
2. **Имя.** Кнопки навигации — константные `aria-label` (год/месяц назад и вперёд). День — читаемая дата, не строка ISO. Сетка — имя от заголовка месяца.
3. **Клавиши.** Навигация месяца: одна остановка Tab, стрелки / Home / End по четырём кнопкам, выключенные пропускаются. Сетка: одна остановка Tab; влево-вправо день, вверх-вниз неделя, Home / End края недели, PageUp / PageDown месяц, они же с Shift — год. Пробел на дне только обновляет черновик. Enter на дне обновляет черновик и выполняет Set. Недоступные дни — нативный `disabled`, стрелки их не берут. Стрелка за край месяца перелистывает месяц.
4. **Фокус.** Сам панель не открывает. Фокус на день ставит родитель: выбранный, иначе сегодняшний, иначе первый доступный. После смены месяца из сетки — отложенный ISO в состоянии `pendingFocusIso`.
5. **Состояния.** Ячейка: `aria-selected` при выборе; `aria-current="date"` у сегодняшнего. Кнопка дня: нативный `disabled` вне границ. Диапазон — `data-*`.
6. **Находки.** Открытые №8 и №14 закрыты проходом 19.08.

## FieldClear

1. **Роль.** Корень — `Icon as="button"` → `<button>`.
2. **Имя.** Обязательный проп `ariaLabel` → `aria-label`. Без него тип не соберётся. Вызывающий код обычно берёт текст из `resolveClearAriaLabel`.
3. **Клавиши.** Нативные Enter / Space. Одна остановка Tab.
4. **Фокус.** Не открывается. После клика фокус возвращает родитель (Input / SearchField ставят фокус в поле).
5. **Состояния.** Нативный `disabled`.
6. **Находки.** Нет.

## FieldError

1. **Роль.** `Text as="p"`. Не интерактивен.
2. **Имя.** Текст ошибки или `placeholder`. Пустая строка ошибки не считается ошибкой. Связь с полем — `id`, который родитель кладёт в `aria-describedby`.
3. **Клавиши.** Не фокусируется. Остановок Tab нет.
4. **Фокус.** Нет.
5. **Состояния.** `aria-live="polite"` на `<p>`.
6. **Находки.** Без `children`, `placeholder` и `reserveErrorSpace` узел не рендерится — полоски в дереве нет.

## FieldLabel

1. **Роль.** `Text as="label"` → `<label>`. Без `children` возвращает `null` — узла нет.
2. **Имя.** Содержимое `children`. Связь с контролом — `htmlFor`, `id` как цель `aria-labelledby`, или оба: Listbox вида `field` и RangeInput ставят `htmlFor` и `id`, кнопку называют через `aria-labelledby`. Вариант только с `id` (Stepper, DateRangeInput, SegmentButton) сам контрол не помечает: связь должна быть обратной.
3. **Клавиши.** Не остановка Tab.
4. **Фокус.** Нет.
5. **Состояния.** Нет.
6. **Находки.** Один компонент обслуживает две модели связи. Путать их в проверке нельзя.

## Fieldset

1. **Роль.** Корень — `<fieldset>`. Заголовок — `Text as="legend"`.
2. **Имя.** Обязательный проп `label` → текст `<legend>`. Без него тип не соберётся. Имя группы — легенда.
3. **Клавиши.** Своих нет. Остановки Tab — у потомков.
4. **Фокус.** Нет.
5. **Состояния.** Нативный `disabled` на fieldset глушит потомков, если его передали.
6. **Находки.** Нет.

## Icon

1. **Роль.** По умолчанию `<span>`. При `as="button"` — `<button type="button">` (дефолт типа в компоненте).
2. **Имя.** У `span` имени нет и не нужно. У кнопки — только то, что передал вызывающий код (`aria-label` / текст). Своего дефолта нет.
3. **Клавиши.** Как у кнопки, если `as="button"`. Иначе не фокусируется.
4. **Фокус.** Нет панели.
5. **Состояния.** Нативный `disabled` при кнопке. `interactive` — канал стилей родителя, не ARIA.
6. **Находки.** Кнопка без `aria-label` и без текста — безымянная. Тип это не запрещает.

## IconButtonRow

1. **Роль.** Корень — `div`. Каждое действие — `Icon as="button"`.
2. **Имя.** У кнопки — `action.ariaLabel`. Без него кнопка `aria-hidden` и `tabIndex={-1}`: в дереве и в табе её нет.
3. **Клавиши.** Без `rovingFocus` каждая именованная кнопка — своя остановка Tab; Enter / Space нативные. С `rovingFocus` одна остановка Tab, стрелки влево и вправо, вверх и вниз, Home, End ходят по доступным именованным действиям. Горизонтальная пара читает `direction` узла и в `rtl` разворачивается. Если проходимого действия нет, у всех кнопок `tabIndex={-1}`. Escape не обрабатывается.
4. **Фокус.** Нет панели. При смене индекса roving вызывает `focus()` на соседе.
5. **Состояния.** Пробрасывает `aria-expanded`, `aria-controls` с действия. `disabled` — нативный.
6. **Находки.** Действие без `ariaLabel` скрыто от вспомогательных технологий намеренно. Слот `control` именуется сам; ряд `ariaLabel` ему запрещает. Цель фокуса слота — первая кнопка внутри; слот рассчитан на вид `icon` с одной кнопкой.

## Input

1. **Роль.** Корень — `div`. Поле — `<input>` с типом `text` по умолчанию: в JSX `type="text"` стоит до спреда `inputProps`, поэтому вызывающий код тип переопределяет.
2. **Имя.** `FieldLabel htmlFor={id}`. Без `label` подписи нет; имя только из `aria-label` / `aria-labelledby` в rest, иначе поле безымянное. Кнопка сброса — `clearAriaLabel` или `resolveClearAriaLabel(label)`: без подписи имя сброса — «Clear». Хвостовое двоеточие подписи в имени сброса срезают.
3. **Клавиши.** Набор текста нативный. Остановки Tab: поле + сброс (если значение непустое и `showClear`).
4. **Фокус.** После сброса фокус возвращается в поле.
5. **Состояния.** `aria-invalid` при ошибке или `invalid`. `aria-describedby` склеивает id ошибки и внешний describedby. Нативный `disabled`.
6. **Находки.** Нет.

## Listbox

1. **Роль.** Корень — `div`. Триггер — `<button aria-haspopup="listbox" aria-expanded>`. Панель без поиска — `<ul role="listbox">`. С `showSearchField` поле — `SearchField` с `role="combobox"` и `aria-autocomplete="list"`, список — `<ul role="listbox">`. Строка — `<li role="option">`. Пустой результат поиска — `li` с `role="presentation"`, не опция.
2. **Имя.** Вид `field`: подпись — `FieldLabel` с `htmlFor` и `id`; имя триггера — `aria-labelledby` подписи и узла значения (пустое: подпись и плейсхолдер). Без `label` в имени остаётся значение или плейсхолдер. Вид `icon`: подпись не рисуется; `aria-label` — `resolveTriggerAccessibleName` из `@ui/a11y` (подпись и значение через пробел). Панель — `aria-label={label || placeholder}`. Имя опции — текст `option.label`. Кнопка сброса — `clearAriaLabel` или `resolveClearAriaLabel(label)`.
3. **Клавиши.** Триггер: Enter / Space переключают; ArrowDown открывает, кроме слота `control` в Toolbar; Escape закрывает. Без поиска в панели одна остановка Tab на активной строке (`tabIndex={0}` у tab-stop, `-1` у остальных). Стрелки, Home, End двигают активную строку без смены выбора. Enter / Space на строке подтверждают. С поиском фокус в поле (`aria-label` из непустого `searchLabel`, иначе из `label` или `placeholder`): стрелки / Home / End без смены DOM-фокуса; Enter подтверждает; Space идёт в поле. Escape — через dismiss. Чекбокс в строке из таба исключён. Остановки закрытого `field`: триггер + сброс, если виден. Шеврон внутри триггера — не кнопка и не остановка Tab.
4. **Фокус.** Без поиска при открытии — DOM-фокус на выбранную или первую доступную строку. С поиском — каретка в поле, активная строка через `aria-activedescendant`. При закрытии — на триггер. Ловушка Tab есть.
5. **Состояния.** Триггер: `aria-expanded`, `aria-controls`, `aria-haspopup`. Поле поиска: `aria-expanded`, `aria-controls`, `aria-activedescendant`. Панель: `aria-multiselectable` при `multiple`. Опция: `aria-selected`, `aria-disabled` (не нативный `disabled`). Чекбокс: `aria-hidden`.
6. **Находки.** Две модели фокуса в одном компоненте: без поиска — DOM-фокус на `<li>`, с поиском — `aria-activedescendant` на поле.

## LocalePicker

1. **Роль.** Обёртка над Listbox, своего корня нет. `showSearchField` всегда включён. `multiple` и `inlineCheckbox` не отдаёт.
2. **Имя.** Как у Listbox. Вид `icon` в тулбаре обязан получить `label` (превью — `Language:`): имя — `Language:` и значение или плейсхолдер.
3. **Клавиши.** Как у Listbox с поиском. В слоте Toolbar закрытый триггер отдаёт стрелки ряду; открывает `Enter` / пробел.
4. **Фокус.** Как у Listbox с поиском: при открытии — поле поиска.
5. **Состояния.** Как у Listbox с поиском.
6. **Находки.** Превью витрины и открытый снимок — срез 10 кодов, не полный iso-639-1.

## Modal

1. **Роль.** Корень — `<dialog>` (`StyledModalDialog`). Внутри — Card. Явного `role` нет: роль даёт нативный `dialog`.
2. **Имя.** Обязательно по типу: `ModalAccessibleName` — объединение `title` и `ariaLabel`. С заголовком имя даёт `aria-labelledby` на id заголовка Card (`titleId` уходит в Card тем же пакетом пропсов), без заголовка — `aria-label`.
3. **Клавиши.** Escape и клик по backdrop — `closedby="any"` + нативный `dialog`. Tab — нативная ловушка модального диалога, не `useFocus`.
4. **Фокус.** Открытие — `showModal()`. Передан `initialFocusRef` — фокус на его узел после `showModal`; не передан — на сам `<dialog>`: панель открывают ради содержимого, Close остаётся по Tab и Esc. Закрытие — `dialog.close()` / `onClose`; возврат фокуса — нативное поведение `<dialog>`, отдельного `returnFocusRef` в коде нет.
5. **Состояния.** Нативный `open` у dialog. Кнопка закрытия — `aria-label` из `closeAriaLabel` (дефолт «Close»).
6. **Находки.** Находка №10 закрыта проходом 19.08. Известное ограничение: `<Modal title="" />` проходит тип и имени не даёт — непустую строку TypeScript без хаков не выражает; витрина пустую строку срезает, вызывающий код обязан передать текст.

## ProgressBar

1. **Роль.** Корень — `div`. Полоса — `div` с `role="progressbar"`.
2. **Имя.** Только `aria-label` / `aria-labelledby` с вызывающего кода. Процент рядом скрыт `aria-hidden` и в имя не входит. Без пропов имени нет.
3. **Клавиши.** Не фокусируется. Остановок Tab нет.
4. **Фокус.** Нет.
5. **Состояния.** `aria-valuemin={0}`, `aria-valuemax={100}`, `aria-valuenow={percent}`.
6. **Находки.** Открытая №12.

## RadioButton

1. **Роль.** С `children` корень — `<label>` (`StyledRadioButtonRoot`), внутри `<input type="radio">`. Без `children` корень — сам `input`.
2. **Имя.** С `children` — текст внутри обёртки-`label` (не `htmlFor`, не `FieldLabel`). Без `children` имени нет, пока вызывающий код не передал `aria-label` / `aria-labelledby` на `input`.
3. **Клавиши.** Нативные для radio group (стрелки между одноимёнными `name`, Space). Одна остановка Tab на группу, если браузер так ведёт radio.
4. **Фокус.** Нет панели.
5. **Состояния.** Нативные `checked`, `disabled`, `name`, `value`.
6. **Находки.** Публичное имя в карту не внесено: корень условный.

## RangeInput

1. **Роль.** Корень — `div`. Триггер — `<button aria-haspopup="dialog">`. Панель — `div` с `role="dialog"` и `aria-modal`. Пресеты — `<ul>` / `<li>` / `<button>`. Поля — группа `role="group"`.
2. **Имя.** Подпись триггера — `FieldLabel` с `htmlFor` и `id`; имя триггера — `aria-labelledby` подписи и узла значения (пустое: подпись и `placeholder`). Без `label` в имени остаётся значение или плейсхолдер. Панель: при `title` — `aria-labelledby` на id заголовка (`titleLevel`, дефолт `h2`); без title — `aria-label` «Custom range». Группа полей — тот же `aria-labelledby` заголовка. Поля From/To своего `label` не получают. Кнопка сброса при `onClear` — `clearAriaLabel` или `resolveClearAriaLabel(label)`: без подписи имя сброса — «Clear».
3. **Клавиши.** Триггер: Enter / Space. Escape закрывает (`useAnchoredDismiss`); отдельного обработчика Escape в модуле нет. Enter в поле From/To применяет черновик. Стрелки панель не обрабатывает. Остановки Tab закрытого: триггер + сброс; шеврон внутри триггера — не кнопка и не остановка Tab. В панели: пресеты (каждая кнопка), два поля, их сбросы, кнопка Apply.
4. **Фокус.** При открытии — поле From (`fromInputRef`). При закрытии — триггер. Ловушка Tab есть.
5. **Состояния.** Триггер: `aria-expanded`, `aria-controls`, `aria-haspopup="dialog"`. Поля: `aria-invalid` / `aria-describedby` при ошибке панели.
6. **Находки.** Открытая №7 — имена From/To.

## ScrollPort

1. **Роль.** Корень и вьюпорт — `div`. Роли нет.
2. **Имя.** Своего нет. Имя, если нужно, задаёт вызывающий код на потомках.
3. **Клавиши.** Нативная прокрутка. Остановок Tab нет, пока внутри нет фокусируемых.
4. **Фокус.** Нет.
5. **Состояния.** Веер края — `data-*` на корне, не ARIA.
6. **Находки.** Из кода не следует, объявлен ли регион прокрутки для скринридера.

## SearchField

1. **Роль.** Корень — `div`. Поле — `<input type="search">`. Иконка секции — `span`. Сброс — `FieldClear` / кнопка.
2. **Имя.** `FieldLabel htmlFor={id}`. Без `label` подписи нет; имя поля — только если вызывающий код передал aria-пропы в rest, иначе поле безымянное. Кнопка сброса — `clearAriaLabel` или `resolveClearAriaLabel(label, 'Clear search')`: без подписи имя сброса — «Clear search». Хвостовое двоеточие подписи в имени сброса срезают.
3. **Клавиши.** Набор текста нативный. Остановки Tab: поле + сброс при непустом значении. Иконка секции не фокусируется.
4. **Фокус.** После сброса фокус возвращается в поле.
5. **Состояния.** Нативный `disabled`. Listbox с `showSearchField` навешивает на это поле `role="combobox"`, `aria-expanded`, `aria-controls`, `aria-activedescendant`, `aria-autocomplete`.
6. **Находки.** В панели Listbox с поиском видимый `label` передаётся, только когда `searchLabel` непустой; имя поля всё равно даёт `aria-label` из `searchLabel`, иначе из `label` или `placeholder`.

## SegmentButton

1. **Роль.** Корень — `div`; при `label` — `role="group"` и `aria-labelledby`. Сегменты — кнопки `SegmentButtonParts`.
2. **Имя.** Подпись — `FieldLabel id={labelId}` без `htmlFor`. Без `label` группы нет. Имя сегмента — его `label` (текст кнопки).
3. **Клавиши.** Нативные Enter / Space на каждом сегменте. Отдельного roving нет: столько остановок Tab, сколько сегментов (2 или 3).
4. **Фокус.** Нет панели.
5. **Состояния.** На сегменте: `aria-current="true"` при `active`; опционально `aria-expanded`, `aria-haspopup`, `aria-controls`.
6. **Находки.** Нет.

## SegmentButtonParts

1. **Роль.** Корень — `div`. Часть — `<button>`. Разделитель — `span aria-hidden`.
2. **Имя.** Текст `action.label` внутри кнопки. `title` — нативный tooltip, в имя не подставляется.
3. **Клавиши.** Как у нативной кнопки. 2–3 остановки Tab.
4. **Фокус.** Нет.
5. **Состояния.** Те же, что у SegmentButton, плюс `data-action` для Enter-маршрутизации DateRangeInput.
6. **Находки.** Ряд без оболочки сам группой не объявлен.

## Sidebar

1. **Роль.** Корень — `div`. Слот панели — `<aside>` (`StyledSidebarSlot`). Карточка внутри — Card.
2. **Имя.** `aria-labelledby` на `<aside>` строится как `` `${id}-title` `` только при `title` и `id`. Без пары слот имени не получает. Кнопка сворачивания — `iconAriaLabel` (дефолт «Close panel»).
3. **Клавиши.** Своих нет. Остановки Tab — контент страницы, действия шапки, кнопка сворачивания, содержимое панели.
4. **Фокус.** Это не модалка: ловушки Tab нет, фокус при открытии и закрытии код не переставляет. Слот при закрытии остаётся в DOM до конца анимации с `aria-hidden={!isRendered}`.
5. **Состояния.** Кнопка сворачивания: `aria-expanded`, `aria-controls`. Слот: `aria-hidden` пока не смонтирован.
6. **Находки.** Открытая №13. Возврат фокуса при закрытии из кода не следует.

## Spinner

1. **Роль.** Корень — `div`. Индикатор — `div` с `role="status"`.
2. **Имя.** `aria-label` на индикаторе, дефолт «Loading». Видимая подпись (`children`) — отдельный текст, на `status` не завязана.
3. **Клавиши.** Не фокусируется.
4. **Фокус.** Нет.
5. **Состояния.** `role="status"` подразумевает live polite. Отдельный `aria-live` не ставится.
6. **Находки.** Из кода не следует, дублирует ли скринридер дефолтный `aria-label` и видимую подпись.

## Stepper

1. **Роль.** Корень поля — `div`. Значение — `<input type="text" role="spinbutton">`. Стрелки — `<button>`.
2. **Имя.** Тип требует ровно одно из: `label`, `aria-label`, `aria-labelledby`. При `label` — `FieldLabel id={labelId}` и `aria-labelledby` на spinbutton (не `htmlFor`). Стрелки — константы «Increase» / «Decrease».
3. **Клавиши.** ArrowUp / ArrowDown на поле меняют значение. Home / End / Enter / Escape поле не обрабатывает. Остановки Tab: поле + две стрелки (три).
4. **Фокус.** Клик по ячейке значения ставит фокус в input. Панели нет.
5. **Состояния.** `aria-valuenow`, `aria-valuemin`, `aria-valuemax` на input. Нативный `disabled`.
6. **Находки.** Нет.

## Switch

1. **Роль.** Корень всегда `<label>` (`StyledSwitchRoot`). Внутри скрытый `<input type="checkbox" role="switch">`. Дорожка — `span aria-hidden`.
2. **Имя.** С `children` — текст внутри `label`. Без `children` обёртка остаётся, текста нет: имя только из `aria-label` / `aria-labelledby` на input. Пример в шапке файла это допускает.
3. **Клавиши.** Нативные Space на checkbox. Одна остановка Tab.
4. **Фокус.** Нет.
5. **Состояния.** Нативный `checked` / `disabled` плюс `role="switch"` (подразумевает `aria-checked` от состояния checkbox).
6. **Находки.** Открытая №1 — временно снят с карты тегов.

## Table

1. **Роль.** Клип — `div`. Таблица — `<table>`. Секции — `thead` / `tbody` / `tfoot`, строки — `tr`, ячейки — `td`/`th`. Панели add/edit — `div role="dialog" aria-modal`.
2. **Имя.** У самой таблицы `aria-label` в коде нет. Чекбоксы выбора — константные `aria-label`. Кнопка «+» — «Add row». Диалоги — «Add row» / «Edit row». Отдельной колонки выбора нет. Чекбокс стоит в lead ячейки; имя — константы шапки и группы и `Select row ${rowKey}` у строки. Резерв слота в шапке — `aria-hidden`, не подпись.
3. **Клавиши.** Ячеек-кнопок как сетки нет: фокус идёт по чекбоксам, кнопке добавления, полям панелей. ArrowDown на кнопке добавления строки открывает панель. Escape закрывает панель (`useAnchoredDismiss`). Enter в подсказке add/edit упомянут как сохранение — обработчик на панели в этом модуле не виден, поведение полей задаёт вызывающий код. Остановки Tab: по одному на каждый интерактив в строке / шапке; в диалоге — поля и действия панели.
4. **Фокус.** При открытии add/edit — первое поле ввода строго внутри узла панели, не кнопка шапки и не чекбокс. Add: `returnFocusRef` на кнопку «+». Edit: на якорную строку. Ловушка Tab у панели есть.
5. **Состояния.** Чекбоксы — нативный `checked`. Диалоги — `aria-modal`. Ошибка панели — `aria-describedby` на полях, если id передан.
6. **Находки.** Находка №11 закрыта проходом 19.08. Имя самой `<table>` из кода не следует.

## Toolbar

1. **Роль.** Корень — `div` с `role="toolbar"`.
2. **Имя.** Обязательный проп `ariaLabel` → `aria-label`. Без него тип не соберётся.
3. **Клавиши.** Ряд действий с `rovingFocus`: одна остановка Tab, стрелки влево и вправо, вверх и вниз, Home / End. Горизонтальная пара в `rtl` разворачивается. Enter / Space — нативные на текущей кнопке. Если проходимого действия нет, у всех кнопок `tabIndex={-1}`.
4. **Фокус.** Нет панели.
5. **Состояния.** Пробрасываются с действий ряда.
6. **Находки.** Превью витрины ставит LocalePicker вида `icon` четвёртым окном, после часов, эпизода и субтитров; имя триггера — `Language:` и значение или плейсхолдер. Панель выбора языка в этом спеке не открывают.

## ProfileMenu

1. **Роль.** Корень — `div`. Триггер — `Icon as="button"` с `aria-haspopup="dialog"`. Панель — Card с `role="dialog"` и `aria-modal`. Правовые ссылки — `<nav aria-label="Legal">` и `Link`.
2. **Имя.** Триггер — `aria-label={`Profile menu for ${displayName}`}`. Панель — `aria-labelledby` на приветствие (`<p id={titleId}>`). Ссылки — видимый текст.
3. **Клавиши.** Триггер — Enter / Space / ArrowDown. Escape закрывает панель. Сегменты Profile / Sign out — отдельные остановки Tab. Ссылки — нативный Tab. Остановки закрытого меню: одна (триггер). В панели: Close, Profile, Sign out, две ссылки.
4. **Фокус.** При открытии — сегмент Profile (`profileActionRef`), не Close. При закрытии — триггер. Ловушка Tab есть.
5. **Состояния.** Триггер: `aria-expanded`, `aria-controls`, `aria-haspopup="dialog"`. Панель: `aria-modal`.
6. **Находки.** Открытая №3 — ссылки сняты с карты тегов. `onClick` на ссылке только закрывает меню при навигации.

## Сценарий клавиатурного прохода

Для каждого виджета витрины, когда до него дойдёт проход компонента:

1. Tab до контрола. Заголовок Card не должен стать остановкой.
2. Открыть (Enter / Space / ArrowDown — по карточке). Куда встал фокус?
3. Пройти стрелки, Home, End. Одна залитая / активная строка?
4. Escape. Фокус вернулся на триггер? Значение не закоммитилось там, где так задумано?
5. Закрыть с подтверждением (Enter / Apply / Set). Значение применилось?
6. Скринридер: имя триггера, имя панели, состояния `aria-expanded` / `aria-selected` / `aria-invalid`.

Playwright и слепки дерева — шаг 3в-2, этот файл их не подменяет. Шаг 3в-2 живёт командой `test:a11y` из `package.json`.
