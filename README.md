# Vite + React + TypeScript starter

Стартер с нейтральным UI-китом: примитивы, иконки, тема, тосты и витрина компонентов. Это хаб для продуктов на том же стеке — отсюда копируют только нужные части UI; витрину в продукт не переносят.

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`. Типы и линт: `npx tsc -b`, `npx eslint src --max-warnings 0`.

## Витрина

После старта dev-сервера откройте [/showcase](http://localhost:5173/showcase) — живая демонстрация примитивов и паттернов кита.
